# Sons padrão dos lances / Default move sounds

move, check, capture, castle, end: sons do Lichess (repositório lichess-org/lila, pasta public/sound),
recortados e convertidos para .wav. Verifique a licença no repositório do Lichess antes de redistribuir.
ok e bad (puzzles) são sintetizados pelo app (src-tauri/src/sounds.rs).
